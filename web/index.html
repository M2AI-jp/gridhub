あそびかた

GridHub は、開発をそのまま JRPG すごろくにしたゲームです。道の上のマス1つ = テスト1件 = モンスター1体。テストが通るとモンスターを倒して1マス進みます。キャラクターはモジュールを1つずつ担当するエージェント（と人間）。

1. 指令書を読む

gridhub brief <ID> に、いまのダンジョン・いま戦うテスト・受け継いだ技・前の自分の日誌が出ます。

2. 1マスずつ歩く

いちばん手前の落ちているテストだけを通して gridhub step <ID>。何度でも、罰なし。倒したモンスターには赤い斜線。

3. 出口で宣言

全部倒したら gridhub check <ID>。町から今までをまとめて走らせる一発勝負。通れば赤ペンのはなまる。

4. 負けたら町から

宣言に落ちると Lv−1、最後の町からやり直し。間のはなまるは消しゴムで消され、町の commit に戻ります（変更は stash の墓に残る）。

5. 町 = セーブ

町に着くと、縄張りの変更を git commit します。看板に commit a1b2c3d。こまめにセーブするほど、負けても失うものが小さい。

6. 中ボス = 結合ゲート

道が合流する城壁。仲間がそろうと結合テスト（連携）。HP はテストの数。負けると責任のある仲間だけ町へ。

7. 王様の城 = ハンコ

人間が決めるべき所は、人間のハンコで進みます。

8. 冒険の書

起きたことは追記専用のセーブデータ（ハッシュの鎖）に残ります。判定ファイルは GM が封印。改ざんは「呪い」として見つかり、記録の番号（#seq）で gridhub load <seq> と、どの時点の盤面にも戻せます。

積み上げ

  • 復活: 前に倒したテストが落ちると、赤い丸で復活して見える（リグレッション）。
  • 強敵と技: 2回以上負けたテストを倒すと「強敵を倒した」。その直後の日誌が技になり、次の代（出撃）に受け継がれる。
  • ちいさなメダル ◎: ダンジョンの出口を一発で抜けた数。モンスター図鑑: 計画したテストのうち、いま通っている数。
  • 作戦: いのちだいじに / バッチリがんばれ / ガンガンいこうぜ。エージェントの動き方が変わる（ルールは変わらない）。

くわしくは docs/GAME_DESIGN.md と docs/RULEBOOK.md。CLI は gridhub（masume も同じ）。

新しい冒険

どんなアプリを作りたい？

「○○のようなアプリを作りたい」と書くと、GM の LLM が、開発のロードマップ全体を5mm方眼ノートの世界地図にします。テスト1件が1マス。モジュールごとのキャラクター（エージェント）の道が、中ボス（結合テスト）で合流します。

判定（E2E）が 127.0.0.1 に手元のサーバーを立てるときに使います。ゲームはローカルのままです。ただし Codex の設定は localhost だけに絞れないので、開けているあいだはエージェントがインターネットにも出られます。codex にだけ効きます（チェックすると、生まれた冒険の出撃にも持ち越します）。

GM は地図（quest.map.json）と最初の判定（E2E）を書くだけで、アプリは作りません。作るのは、このあと出撃させるキャラクターたちです。

出撃させる

      
選んだキャラクターごとにエージェントを1人ずつ出撃させます。エージェントは指令書を読み、いちばん手前の落ちているテストから1件ずつ倒して進みます（作戦で、どこまで進むかが変わります）。中ボス（結合テスト）はパーティがします。本物の LLM を呼ぶので、時間と利用料がかかります。

      

        
        
        
      

      

        
        
1マスずつ gridhub step で確かめ、全部のテストが通るまで宣言しない。1つのダンジョンを抜けたら（宣言に2回失敗したら）止まる。

        
小さく変えて step を回し、全部通ったら宣言。1つのダンジョンを抜けたら（宣言に2回失敗したら）止まる。

        
次の町まで、ダンジョンを続けて進んでよい。町でセーブしたら・ゲートで待機になったら（宣言に2回失敗したら）止まる。
