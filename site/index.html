GridHub とは 遊び方 入れる GitHub

開発の進行管理 × JRPG のすごろく

テスト1件が1マス。
方眼ノートのすごろくで、開発を進める。

GridHub は、テストを1件ずつ通して開発を進める進行管理ツールです。タスクの E2E テストが道のマスになり、通すたびに駒が1マス進みます。自己申告では1マスも進みません。AI エージェントと人間が、同じ盤面を見て進めます。

入れて遊ぶ GitHub で見る

GridHub とは

開発の言葉を先に、ゲームの言葉を添え書きにしています。GridHub 自体は Node.js 22 以上と Git だけで動き、外部パッケージはありません。

テスト1件 ＝ 1マス
タスクの判定（E2E テスト）に書いたテスト1件ずつが、道のマス（雑魚モンスター）になります。gridhub step は、いちばん手前の落ちているテストだけを走らせて、1マスずつ歩きます。何度歩いても罰はありません。
タスク ＝ ダンジョン
全部のテストを倒したら、出口で宣言します（gridhub check）。町から今までの判定をまとめて走らせ、落ちたら Lv が1つ下がって、町からやり直しです。
町 ＝ Git のコミット
町に着くと、担当のファイルだけをコミットします（セーブ）。宣言に負けたら町のコミットに戻り、戻す前の変更は git stash（墓）に残ります。
キャラクター ＝ AI と人間
モジュールの担当ごとに1人。AI エージェント（Claude Code・Codex）も人間も駒になります。縄張り（ファイルの範囲）の外は書けません。エージェントには作戦を出して出撃させます。
中ボス・魔王 ＝ 結合テスト
担当ごとに分かれた道が、結合テストの砦で合流します。仲間がそろうとボス戦が始まり、章のあがりの結合 E2E が魔王の城です。
王様の城 ＝ 人間のハンコ
承認・契約・鍵のように、人間にしか決められないマスは、人間がハンコを押して進めます。エージェントは代わりに押せません。
余白のマス
道には、別の担当との会話・町の住人との雑談・作っている製品の瓦版を置きます。仕事のマスのあいだにある、開発に関係する良い余白です。
冒険の書 ＝ ハッシュの鎖
進み具合は、ハッシュでつないだ記録（.masume/log.jsonl）に残ります。判定のファイルは封印され、書き換えると記録に残ります。会話が途切れても、gridhub brief を読めば誰でも続きから始められます。

遊び方は3つ

1Mac のアプリで

GridHub.app をダブルクリックして、フォルダを選ぶだけです。冒険の書があれば盤面が、無ければ願いを書く入口が開きます。冒険づくり・出撃・ハンコ・ボス戦は、窓の中のボタンでできます。

窓を閉じれば、盤面のサーバーも止まります。

25分のチュートリアルで

勇者（あなた）と見習いAI の2人で、名前入りのあいさつカードを作ります。キャラクターの「手で進める」で、見本を写す → 保存 → 歩く → 宣言判定・ハンコ。

claude が無くても、最後まであがれます。

3自分のアイデアで、Claude と

「メモのアプリを作りたい」と願いを書くと、GM（Claude）が地図と、タスクごとの E2E テストを書いて封印します。キャラクターごとに Claude Code を出撃させ、あなたは盤面でハンコを押します。

gridhub quest "メモのアプリを作りたい"
gridhub party --agent claude

画面

入れる

ソースは GitHub にあります: github.com/M2AI-jp/gridhub（MIT ライセンス）。

Mac のアプリ

要るもの: macOS 13 以上・Node.js 22 以上・Command Line Tools（xcode-select --install）。Xcode は要りません。ターミナルを使うのは、最初に組み立てる1回だけです。

git clone https://github.com/M2AI-jp/gridhub.git && cd gridhub
npm run mac        # dist/GridHub.app ができる

dist/GridHub.app を「アプリケーション」フォルダに入れて開きます。署名していないので、はじめて開くときは右クリックして「開く」を選んでください。

コマンドで

要るもの: Node.js 22 以上と Git。版 0.3.0 を GitHub から入れます（npm には出していません）。

npm install -g github:M2AI-jp/gridhub#v0.3.0
gridhub --version  # gridhub 0.3.0 (rules 1)

遊び方は、GitHub の README の「5分で始める」と、チュートリアル（quests/tutorial/README.md）にあります。

Claude Code

願いから冒険を作る・エージェントを出撃させるときに使います。チュートリアルには要りません。

npm install -g @anthropic-ai/claude-code

GridHub は GridHub で作っています

このリポジトリ自体が、GridHub の冒険です。書記・伝令・賢者クロード・地図職人・大工などのキャラクターが、自分の縄張りのファイルだけを書き、封印された判定を通して、第1章から1マスずつ進めてきました。どのマスを、いつ、どのコミットで抜けたかは、冒険の書（gridhub log）に全部残っています。
