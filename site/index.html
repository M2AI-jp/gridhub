こんな悩み、ありませんか？

  • AI に開発を任せたけれど、いまどこまで進んでいるのか分からない。

  • 「できました」と言われても、本当に動くのか不安になる。

  • タスク管理は文字のリストばかりで、見ていてちっとも楽しくない。

GridHub は、開発の進み具合をすごろくの盤面にします。見ればすぐ分かって、進むのが楽しくなります。

GridHub の特長

進み具合が、ひと目で分かる

担当ごとのキャラクターが、方眼ノートの道を進みます。誰がどこまで進んで、ゴールまであと何マスか。盤面を見ればすぐに分かります。

合格したぶんだけ進める

マスの1つ1つは、「メモを1件書くと、一覧のいちばん上に出てくる」のような小さなテストです。合格しないと先へ進めないので、「できたつもり」が起きません。

AI とパーティを組める

Claude Code（Anthropic）か Codex（OpenAI）が、担当ごとのキャラクターになって冒険に出発します。あなたも勇者として、同じ盤面で遊べます。

途中で止まっても、セーブした場所から

進み具合は「冒険の書」に、作ったファイルは Git に、自動でセーブされます。AI との会話が途切れても、続きのマスから再開できます。セーブは GitHub に送っておくこともできます。

AI がいちばん力を出せる大きさで、地図ができています

AI は、小さくてはっきりした仕事が得意です。いっぽうで、長い会話では前のことを忘れやすく、頼んでいない所まで手を広げがちです。GridHub の地図は、その性質に合わせて、1マスから大ボスまでの大きさが決めてあります。

数分30〜90分数時間数日

  1. マス（モンスター）

    テスト1件数分

    1回に1つのことだけ直して、確かめます。小さいので、AI が迷いません。

    例:「メモを1件書くと、一覧のいちばん上に出てくる」

  2. ダンジョン

    タスク30〜90分（マス2〜6個）

    AI が1回の会話で終えられる量です。出口では、それまでのマスをまとめて確かめ直します。

    例:「メモを保存して、一覧に出す」

  3. 町（宿屋）

    セーブ（Git のコミット）ダンジョン2〜3つごと

    着くと自動でセーブします。負けても、ここからやり直せます。

  4. 中ボス

    結合テスト数時間に1回

    担当どうしの仕事が、はじめてつながる所です。仲間がそろうと、戦いが始まります。

    例:「アプリを止めて動かし直しても、メモが消えていない」（保存の担当と、サーバーの担当が合流）

  5. 王様の城

    あなたのハンコ大ボスの前に必ず1つ

    デザインの承認や本番の鍵など、あなたにしか決められないことだけが、ここに来ます。

    例:「ブラウザで実際に触ってみて、よければハンコ」

  6. 大ボス（魔王の城）

    章の最後の結合テスト数日に1回

    作りたかったものが本当にできた、と言える場面を外から確かめます。勝つとエンディングです。

    例:「メモを書いて、一覧で見られる。探す・直す・消すもできる」

  7. イベント（寄り道）

    開発に関係するおしゃべり道の途中

    進むのを止めない、ひと息のマスです。中ボスの前で別の担当と日誌を見せ合ったり、宿屋の主人に「テスト12件、通ってきたね」と声をかけられたり、作っている製品の瓦版が届いたりします。

テストは、あなたが書かなくて大丈夫

テストは「こう動いたら合格」を確かめる小さなプログラムです。画面やコマンドを外から動かして確かめます。AI のゲームマスター（Claude Code か Codex）が、地図といっしょに用意します。AI の仲間がテストを都合よく書き換えると、すぐに分かるようになっています。

ゲームとして、ここが楽しい

練習は何度でも、本番は一発勝負

マスでの戦いは、何度負けてもペナルティがありません。ダンジョンの出口だけは一発勝負で、負けるとレベルが下がり、町まで戻されます。

倒したモンスターが、仲間になる

一度合格したテストは、そのあともずっと一緒に戦ってくれます。あとの変更で壊れると、モンスターが復活して、すぐに分かります。

仲間がそろうと、ボス戦が始まる

それぞれの道を進んだ仲間が、中ボスの砦で合流します。原因の分かる負け方なら、やり直すのはその担当だけです。

あなたは、作戦を出す指揮官

「1マスずつ慎重に」から「次の町まで一気に」まで、AI の仲間に作戦を出せます。動くのは AI、決めるのはあなたです。

信頼が増えるほど、先が見えてくる

あなたには地図の全部が見えています。AI の仲間には、レベルに合わせた少し先までしか見せないので、頼んでいない先の仕事に手を出しません。

代がかわっても、技は受け継がれる

AI の会話が途切れても、次の代のキャラクターが、先代の日誌と苦労して覚えた技を受け継ぎます。盤面には「3代目」のように出ます。

集めて、眺めて、また遊びたくなる

一発合格のメダル、合格したテストのモンスター図鑑、テストのまちがいを見つけたときの宝箱。章の最後には、その冒険の記録から毎回ちがうエンディングが流れます。

方眼ノートの手ざわり

盤面は、B5 の縦の5mm方眼ノートに手で描いたすごろくです。駒が次のページへ進むと、ノートがめくれます。

遊び方

  1. 1

    作りたいものを書く

    「メモアプリを作りたい」のように、作りたいものを一文で書きます。

  2. 2

    地図ができる

    AI（Claude Code か Codex）がゲームマスターになって、作業を担当ごとに分け、テストのマスを並べた地図を作ります。

  3. 3

    冒険に出発

    AI のキャラクターが、担当ごとに道を進みます。あなたは盤面を眺めながら、大事なところでハンコを押します。

まずは5分のチュートリアルから。AI がなくても、最後まで遊べます。

はじめる

必要なもの

  • Mac（macOS 13 以上）
  • Node.js 22 以上（https://nodejs.org/）
  • Command Line Tools（Git が入っています。ターミナルで xcode-select --install）

  • Claude Code（Anthropic）か Codex（OpenAI）のどちらか1つ。それぞれのアカウントか API キーでログインして使います。AI の利用料は、Anthropic か OpenAI にかかります。GridHub 自体は無料です。（5分のチュートリアルだけなら要りません）

    Claude Code の入れ方
    npm install -g @anthropic-ai/claude-code
    Codex の入れ方
    npm install -g @openai/codex
  • GitHub … GridHub は GitHub からダウンロードします。セーブを GitHub に送ることもできます（送らなくても遊べます）。
  • Linear や Jira を使っているチームは、進み具合をそちらにも映せます（任意。それぞれの API キーを使います）。

Mac アプリで遊ぶ

  1. ターミナルで次のコマンドを実行します（最初の1回だけです）。

    git clone https://github.com/M2AI-jp/gridhub.git
cd gridhub
npm run mac

  2. できあがった dist/GridHub.app を「アプリケーション」フォルダに移して、ダブルクリックで開きます。

※「開けません」と表示されたときは、右クリックして「開く」を選んでください。

コマンドラインで遊ぶ

npm install -g github:M2AI-jp/gridhub#v0.3.0
gridhub --help

コマンドやしくみのくわしい話は、エンジニアの方へのページにあります。
