退屈な開発を、
楽しいゲームに。

テストが1つ通るたびに、キャラクターが1マス進む。AI エージェントとパーティを組んで、ゲーム感覚で開発を進めよう。

Mac で遊んでみる GitHub を見る

こんな悩み、ありませんか？

  • AI に開発を任せたけれど、いまどこまで進んでいるのか分からない。

  • 「できました」と言われても、本当に動くのか不安になる。

  • タスク管理は文字のリストばかりで、見ていてちっとも楽しくない。

GridHub は、開発の進み具合をすごろくの盤面にします。見ればすぐ分かって、進むのが楽しくなります。

GridHub の特長

進み具合が、ひと目で分かる

担当ごとのキャラクターが、方眼ノートの道を進みます。誰がどこまで進んで、ゴールまであと何マスか。盤面を見ればすぐに分かります。

テストに通ったぶんだけ進める

マスの1つ1つが、テスト1件です。テストに通らないと先へ進めないので、「できたつもり」が起きません。

AI とパーティを組める

Claude Code や Codex が、担当ごとのキャラクターになって冒険に出発します。あなたも勇者として、同じ盤面で遊べます。

ボス戦で、みんなの仕事を確かめる

担当ごとの道は、結合テストのボス戦で合流します。全員そろって勝てば、その先へ進めます。

途中で止まっても、セーブした場所から

進み具合は「冒険の書」に自動でセーブされます。AI との会話が途切れても、続きのマスから再開できます。

寄り道も、開発の一部

道の途中では、仲間との会話や町の人とのおしゃべり、作っている製品のニュースが起きます。ただのタスク管理にはない、ちょっとした楽しみです。

ゲームの中身は、いつもの開発です

見た目はすごろくでも、中で動いているのはふだんの開発の道具です。

ゲームの言葉開発の言葉

ボス戦結合テスト
王様の城あなたの承認（ハンコ）
冒険の書進み具合の記録

遊び方

  1. 1

    作りたいものを書く

    「家計簿アプリを作りたい」のように、作りたいものを一文で書きます。

  2. 2

    地図ができる

    AI がゲームマスターになって、作業を担当ごとに分け、テストのマスを並べた地図を作ります。

  3. 3

    冒険に出発

    AI のキャラクターが、担当ごとに道を進みます。あなたは盤面を眺めながら、大事なところでハンコを押します。

まずは5分のチュートリアルから。AI がなくても、最後まで遊べます。

画面

はじめる

Mac アプリで遊ぶ

必要なもの: macOS 13 以上・Node.js 22 以上・Command Line Tools

  1. ターミナルで次のコマンドを実行します（最初の1回だけです）。

    git clone https://github.com/M2AI-jp/gridhub.git
cd gridhub
npm run mac

  2. できあがった dist/GridHub.app を「アプリケーション」フォルダに移して、ダブルクリックで開きます。

※「開けません」と表示されたときは、右クリックして「開く」を選んでください。

コマンドラインで遊ぶ

npm install -g github:M2AI-jp/gridhub#v0.3.0
gridhub --help

AI といっしょに遊ぶときは、Claude Code か Codex を用意しておきます。
