# ASSUMPTIONS — 聞かずに決めたこと

- **使う人**: 1 人が自分のパソコンのブラウザで使う（`http://127.0.0.1:3000`）。ログイン・複数ユーザー・クラウド同期はなし。
- **「メモ」**: タイトル（任意、100 文字まで）と本文（任意、10000 文字まで）。どちらかは必須。タグ・画像・Markdown 表示はなし（本文は素のテキストを改行つきで表示）。
- **「一覧」**: 新しく作った順。検索（タイトルと本文の部分一致）、編集、削除ができる。ページ分けはなし。
- **保存**: `memos.json` 1 ファイル（外部データベースなし）。サーバーを止めても残る。
- **作り**: Node.js 20+ の標準ライブラリだけの小さな HTTP サーバーが、API と静的ファイル（ビルドなしの ES モジュール）を配る。フレームワーク・バンドラーなし。
- **外部サービス・本物の鍵**: 使わない。人間にしかできないのは「見た目の承認」と「ブラウザで触っての最終確認」だけ（勇者のハンコ）。
- **判定の限界**: 判定にヘッドレスブラウザは使わない（環境依存になるため）。画面は、HTML の構造・描画関数・コントローラ・API クライアントを Node で外から確かめ、`app.mjs` と DOM の最後のつなぎは勇者が実ブラウザで確認する（H2）。
- **判定の差し替え口**: API の判定は `MEMO_STORE_MODULE` で「にせストア」（`checks/fixtures/fake-store.mjs`）を使い、倉庫番を待たずに進められる。結合ゲート G1 で本物のストアとつなぐ。
- **実行**: `node src/server/main.mjs`（`PORT` `MEMO_DATA_DIR` を環境変数で指定可）。
